# v0.1.0 — development milestone

Tag: v0.1.0, commit 318d24a4e2340c95ee5d1e9ce5b41143079f2145.
The existing tag is historical and will not be rewritten. It is not a usable
macOS GPU driver or a verified end-to-end Metal rendering release.

## Included in the tagged source

- SDK-free C11 core with host-memory budget, bounded CPU work/deadlines,
  display mode/HDR state management and EDID/CTA/DisplayID parsing.
- Separate little-endian PCI diagnostics protocol, NVIDIA 10de:28e0 diagnostic
  kext with a disabled-by-default read-only BAR0 probe, and diagnostics App.
- Native macOS 15/26 Intel build and ad-hoc-signing CI; no kext loading test.
- Reusable Vulkan context and offscreen graphics/readback resources. Windows
  RTX 4060 Laptop compute/graphics passed full readback with zero validation
  errors/warnings using the existing NVIDIA ICD. No AMD/Intel execution
  evidence is claimed by this milestone.
- Pinned Mesa 26.2.4 Linux NVK/NAK build, CPU suites and offline SM89 vertex/
  fragment compilation; operation catalog mapping and host session loopback.
- Remove the previous custom mtvk_gpu_* registration/dispatch ABI; Vulkan is
  the vendor-neutral execution interface, not a kernel submission API.

## Not implemented or verified

Darwin NVIDIA ICD, RM/GSP initialization, DMA/IOMMU, GPU BO/VA, channel submit/
fence execution, Metal-to-Vulkan and MSL/AIR translation, accelerator device
registration, IOSurface/WindowServer and hardware display/HDR/reset.

Host fixtures, offline compilation, native build/signature checks and Apple
Paravirtual reference rendering cannot be combined into macOS GPU support.
Actual target-machine authorization, Kernel Collection linkage, kext load,
PCI service attachment and diagnostic round-trip remain unverified.

An existing Git tag is not proof that a GitHub Release or binary assets were
published. Any published development packages retain the limitations above.
